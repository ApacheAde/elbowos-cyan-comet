# Cyan Comet

Full-colour Python 3 neon meteor arcade for ElbowOS.

Steer the cyan comet. Blast falling neon meteors.
A / D or ← → move. Space fire.

## Play
```
pip install -r requirements.txt
python3 cyan_comet.py --play
```

## Record a 9:16 reel
```
python3 cyan_comet.py --record
```
